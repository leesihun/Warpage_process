## Quick Start

### 1. Copy Files
Copy these files to your target location:
```
DataAutoTransfer.exe
config.txt
```

### 2. Edit Configuration
Edit `config.txt` with your settings:
```
TARGET_IP=192.168.1.100
TARGET_DIRECTORY=BackupFolder
USERNAME=backup_user
PASSWORD=your_password
SCHEDULE_TIME=06:00
```

### 3. Test the Setup
```cmd
# Test connectivity
DataAutoTransfer.exe --test

# Test with dry run
DataAutoTransfer.exe --once --dry-run

# Run actual transfer
DataAutoTransfer.exe --once
```

### 4. Start Scheduled Service
```cmd
# Start daily scheduler (runs until Ctrl+C)
DataAutoTransfer.exe
```

## Command Line Options

```
DataAutoTransfer.exe [OPTIONS]

Options:
  -h, --help           Show help message and exit
  -c, --config FILE    Configuration file path (default: config.txt)
  --once               Run transfer once immediately instead of scheduling
  --test               Test connection to target system
  --dry-run            Enable dry run mode (overrides config)
```

## Deployment

### Simple Deployment
1. Copy `DataAutoTransfer.exe` and `config.txt` to target computer
2. Edit `config.txt` with your settings
3. Run executable

### Service Deployment (Windows)
Using NSSM (Non-Sucking Service Manager):

1. **Download NSSM**: https://nssm.cc/download
2. **Install Service**:
   ```cmd
   # Open Command Prompt as Administrator
   nssm install DataAutoTransfer "C:\path\to\DataAutoTransfer.exe"
   nssm set DataAutoTransfer AppDirectory "C:\path\to\exe\directory"
   nssm set DataAutoTransfer Description "Automated daily data transfer service"
   nssm start DataAutoTransfer
   ```

3. **Manage Service**:
   ```cmd
   # Check status
   nssm status DataAutoTransfer
   
   # Stop service
   nssm stop DataAutoTransfer
   
   # Remove service
   nssm remove DataAutoTransfer
   ```

### Task Scheduler Deployment
1. **Open Task Scheduler** (taskschd.msc)
2. **Create Basic Task**:
   - Name: "Data Auto Transfer"
   - Trigger: Daily at desired time
   - Action: Start program
   - Program: `C:\path\to\DataAutoTransfer.exe`
   - Arguments: `--once`
   - Start in: `C:\path\to\exe\directory`

## Configuration Files

### Default config.txt
The executable looks for `config.txt` in the same directory. Example:
```
# Schedule Configuration
SCHEDULE_TIME=06:00
TIMEZONE=Asia/Seoul

# Source Configuration
SOURCE_DIRECTORY=../data
FOLDER_PATTERN=%Y%m%d

# Target Configuration
TARGET_IP=192.168.1.100
TARGET_DIRECTORY=BackupFolder
PROTOCOL=smb
USERNAME=backup_user
PASSWORD=password123

# Options
DRY_RUN=false
RETRY_ATTEMPTS=3
RETRY_DELAY=30
DELETE_AFTER_TRANSFER=false
LOG_LEVEL=INFO
```

### Multiple Configurations
You can have multiple config files for different scenarios:
```
config_production.txt    # Main production config
config_test.txt         # Testing configuration
config_backup.txt       # Backup server config
```

Use with: `DataAutoTransfer.exe --config config_production.txt`

## Troubleshooting

### Common Issues

1. **"Config file not found"**
   - Ensure `config.txt` is in same directory as exe
   - Check file permissions
   - Use full path: `--config C:\full\path\to\config.txt`

2. **"Connection failed"**
   - Run `DataAutoTransfer.exe --test` to diagnose
   - Check IP address and network connectivity
   - Verify credentials and permissions

3. **"Yesterday's folder not found"**
   - Normal behavior - no error if folder doesn't exist
   - Check `SOURCE_DIRECTORY` path in config
   - Verify `FOLDER_PATTERN` matches your folder names

4. **"Permission denied"**
   - Run as Administrator if accessing system folders
   - Check target system permissions
   - Verify user account has access to shared folders

### Debug Mode
For detailed troubleshooting:
```cmd
# Set debug log level in config.txt
LOG_LEVEL=DEBUG

# Run with maximum logging
DataAutoTransfer.exe --once
```
